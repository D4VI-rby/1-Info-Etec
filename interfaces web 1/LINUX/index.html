O que é Linux?

O Linux é um sistema operacional (SO) gratuito e de código aberto que oferece segurança e flexibilidade. Linux é amplamente usado por profissionais de TI para gerenciar diversos tipos de sistemas em computadores, servidores, celulares e outros dispositivos.
O sistema operacional Linux é uma alternativa confiável aos sistemas operacionais mais conhecidos, como Windows e macOS. Desde sua criação em 1991, o Linux se tornou um dos sistemas operacionais mais usados no mundo. O SO Linux foi desenvolvido por Linus Torvalds como uma alternativa semelhante ao Unix (que foi um dos primeiros sistemas operacionais já criados). Ele depende fortemente do kernel Linux para oferecer sua funcionalidade.
Em um sistema operacional, o kernel é o programa responsável por permitir que os usuários controlem o hardware e o software do sistema. Além do kernel, o sistema Linux utiliza diversos componentes, como bibliotecas do sistema e utilitários de espaço, mas todos dependem do kernel para se comunicar e receber comandos dos usuários.
