DISTRIBUIÇÕES LINUX

O que são as distribuições?

As distribuições Linux são sistemas operacionais completos desenvolvidos a partir do kernel Linux, que é o núcleo responsável por controlar o hardware e gerenciar os recursos do computador. Como o kernel sozinho não é suficiente para que um usuário utilize o computador normalmente, diferentes grupos e empresas criam distribuições adicionando interfaces gráficas, programas, drivers, ferramentas de configuração e gerenciadores de pacotes. Cada distribuição possui características próprias e é desenvolvida para atender diferentes públicos e necessidades.
Algumas são voltadas para iniciantes, oferecendo facilidade de uso e instalação, enquanto outras são destinadas a usuários avançados, programadores ou administradores de servidores. Apesar dessas diferenças, todas compartilham a mesma base: o kernel Linux.
